CORPUS TERMINOLOGIQUE FINANCIER ET BANCAIRE — VOLUME 1
Français, international et Afrique centrale
========================================================================

Note : premier volume de travail, non exhaustif et non équivalent à un corpus d'un milliard de mots.
Les définitions sont générales et doivent être vérifiées pour tout usage juridique ou réglementaire.


########################################################################
BANQUE ET COMPTES
########################################################################

1. Compte courant
Définition : Compte bancaire destiné aux opérations quotidiennes : dépôts, retraits, virements, prélèvements et paiements.
Synonymes / variantes : compte à vue; compte de dépôt
Expressions : ouvrir un compte courant; consulter son compte

2. Compte d'épargne
Définition : Compte destiné à recevoir des dépôts conservés en vue d'une épargne, parfois rémunérés selon les conditions contractuelles.
Synonymes / variantes : livret; compte épargne
Expressions : alimenter un compte d'épargne; retirer son épargne

3. Compte joint
Définition : Compte ouvert au nom de plusieurs titulaires, soumis aux règles de fonctionnement convenues avec la banque.
Synonymes / variantes : compte collectif; compte commun
Expressions : ouvrir un compte joint; cotitulaire du compte

4. Compte professionnel
Définition : Compte utilisé pour les opérations financières d'une entreprise, d'un commerçant ou d'un professionnel.
Synonymes / variantes : compte entreprise; compte business
Expressions : encaisser les recettes professionnelles; payer les fournisseurs

5. Compte dormant
Définition : Compte qui n'enregistre plus d'opérations ou de contacts pendant une période définie par les règles applicables.
Synonymes / variantes : compte inactif
Expressions : réactiver un compte dormant; rechercher un compte inactif

6. Compte bloqué
Définition : Compte dont certaines opérations sont temporairement ou légalement restreintes.
Synonymes / variantes : compte gelé; restriction de compte
Expressions : débloquer un compte; compte temporairement indisponible

7. Solde disponible
Définition : Montant immédiatement utilisable sur un compte, compte tenu des opérations comptabilisées et des éventuelles réserves.
Synonymes / variantes : disponibilité; fonds disponibles
Expressions : vérifier le solde disponible; fonds insuffisants

8. Solde comptable
Définition : Montant figurant dans les écritures du compte à un instant donné, avant ou après certains traitements selon le système.
Synonymes / variantes : solde en comptabilité
Expressions : consulter le solde comptable

9. Solde créditeur
Définition : Situation dans laquelle les sommes portées au crédit du compte dépassent les sommes portées au débit.
Synonymes / variantes : position créditrice
Expressions : compte créditeur; présenter un solde créditeur

10. Solde débiteur
Définition : Situation dans laquelle les sommes portées au débit dépassent les sommes portées au crédit.
Synonymes / variantes : position débitrice
Expressions : compte débiteur; autorisation de découvert

11. Relevé de compte
Définition : Document récapitulant les opérations enregistrées sur un compte pendant une période déterminée.
Synonymes / variantes : extrait de compte; statement
Expressions : télécharger un relevé; contester une écriture

12. Date de valeur
Définition : Date retenue par l'établissement pour le calcul des intérêts ou le traitement financier d'une opération.
Synonymes / variantes : date valeur
Expressions : date de valeur d'un dépôt; date de valeur d'un virement

13. Frais de tenue de compte
Définition : Frais prélevés pour la gestion administrative et opérationnelle d'un compte, selon la convention tarifaire.
Synonymes / variantes : commission de gestion; frais de compte
Expressions : prélever les frais de tenue de compte

14. Découvert autorisé
Définition : Facilité permettant au titulaire d'un compte de présenter un solde négatif dans une limite et pour une durée convenues.
Synonymes / variantes : facilité de caisse; autorisation de découvert
Expressions : utiliser son découvert autorisé

15. RIB
Définition : Relevé d'identité bancaire contenant les informations nécessaires pour identifier un compte et recevoir certains paiements.
Synonymes / variantes : coordonnées bancaires
Expressions : communiquer son RIB; enregistrer un bénéficiaire

16. IBAN
Définition : Identifiant international de compte bancaire utilisé dans les pays et systèmes qui l'ont adopté.
Synonymes / variantes : International Bank Account Number
Expressions : vérifier un IBAN; fournir un IBAN

17. BIC
Définition : Code d'identification d'un établissement financier utilisé notamment dans les échanges internationaux.
Synonymes / variantes : code SWIFT
Expressions : renseigner le BIC de la banque

18. Titulaire de compte
Définition : Personne physique ou morale au nom de laquelle un compte est ouvert.
Synonymes / variantes : client titulaire; account holder
Expressions : vérifier l'identité du titulaire

19. Mandataire bancaire
Définition : Personne autorisée par le titulaire à effectuer certaines opérations sur un compte dans les limites d'un mandat.
Synonymes / variantes : représentant; procurataire
Expressions : donner procuration; retirer par mandataire

20. Convention de compte
Définition : Document contractuel définissant les conditions d'ouverture, de fonctionnement, de tarification et de clôture d'un compte.
Synonymes / variantes : contrat de compte
Expressions : signer la convention de compte

########################################################################
PAIEMENTS, VIREMENTS ET TRANSFERTS
########################################################################

1. Virement bancaire
Définition : Opération par laquelle des fonds sont transférés d'un compte vers un autre sur instruction du donneur d'ordre.
Synonymes / variantes : transfert bancaire; bank transfer
Expressions : effectuer un virement; créditer le bénéficiaire

2. Virement permanent
Définition : Virement programmé pour être exécuté automatiquement à intervalles réguliers.
Synonymes / variantes : virement périodique; ordre permanent
Expressions : mettre en place un virement permanent

3. Virement ponctuel
Définition : Virement effectué une seule fois à la demande du donneur d'ordre.
Synonymes / variantes : virement occasionnel
Expressions : envoyer un virement ponctuel

4. Virement interbancaire
Définition : Transfert de fonds entre des comptes tenus par des établissements bancaires différents.
Synonymes / variantes : transfert interbancaire
Expressions : exécuter un virement interbancaire

5. Virement international
Définition : Transfert de fonds entre des comptes situés dans des pays différents.
Synonymes / variantes : transfert transfrontalier
Expressions : recevoir un virement international

6. Ordre de virement
Définition : Instruction donnée à une banque pour transférer une somme déterminée vers un bénéficiaire.
Synonymes / variantes : instruction de paiement
Expressions : émettre un ordre de virement

7. Bénéficiaire
Définition : Personne ou entité désignée pour recevoir les fonds d'un paiement ou d'un transfert.
Synonymes / variantes : destinataire; payee
Expressions : ajouter un bénéficiaire; vérifier le bénéficiaire

8. Donneur d'ordre
Définition : Personne qui initie une opération de paiement ou un transfert.
Synonymes / variantes : émetteur; payeur
Expressions : identifier le donneur d'ordre

9. Prélèvement automatique
Définition : Opération par laquelle un créancier reçoit l'autorisation de demander le débit du compte du payeur selon des modalités définies.
Synonymes / variantes : débit direct; direct debit
Expressions : mettre en place un prélèvement

10. Paiement récurrent
Définition : Paiement effectué à intervalles réguliers, souvent pour un abonnement ou une facture.
Synonymes / variantes : paiement périodique
Expressions : activer un paiement récurrent

11. Paiement instantané
Définition : Paiement dont le traitement et la mise à disposition des fonds sont réalisés en quelques secondes lorsque le système le permet.
Synonymes / variantes : paiement en temps réel
Expressions : envoyer un paiement instantané

12. Paiement marchand
Définition : Paiement effectué par un client au profit d'un commerçant ou d'un prestataire.
Synonymes / variantes : paiement commerçant; merchant payment
Expressions : payer chez un marchand

13. Paiement sans contact
Définition : Paiement initié en approchant une carte ou un appareil compatible d'un terminal.
Synonymes / variantes : contactless payment
Expressions : payer sans contact

14. Paiement refusé
Définition : Opération de paiement rejetée par le système ou l'établissement pour un motif technique, réglementaire ou financier.
Synonymes / variantes : transaction rejetée
Expressions : paiement refusé pour fonds insuffisants

15. Transaction en attente
Définition : Opération initiée mais dont le traitement ou la confirmation n'est pas encore achevé.
Synonymes / variantes : opération pending; transaction pending
Expressions : vérifier une transaction en attente

16. Transaction annulée
Définition : Opération dont l'exécution a été annulée selon les règles du service utilisé.
Synonymes / variantes : paiement annulé
Expressions : demander l'annulation d'une transaction

17. Remboursement
Définition : Opération consistant à restituer tout ou partie d'une somme précédemment payée.
Synonymes / variantes : refund; reversement
Expressions : demander un remboursement

18. Rétrofacturation
Définition : Procédure de contestation d'une opération par laquelle le montant peut être restitué au payeur selon les règles du réseau ou du contrat.
Synonymes / variantes : chargeback
Expressions : ouvrir un dossier de rétrofacturation

19. Compensation interbancaire
Définition : Processus de calcul des positions réciproques entre établissements avant règlement des soldes.
Synonymes / variantes : clearing
Expressions : présenter une opération à la compensation

20. Règlement
Définition : Transfert effectif des fonds destiné à éteindre une obligation de paiement entre parties.
Synonymes / variantes : settlement; dénouement
Expressions : procéder au règlement d'une transaction

########################################################################
CARTES ET MONÉTIQUE
########################################################################

1. Carte de débit
Définition : Carte permettant de régler des achats ou de retirer des espèces par débit d'un compte associé.
Synonymes / variantes : carte bancaire à débit
Expressions : payer par carte de débit

2. Carte de crédit
Définition : Carte permettant d'utiliser une ligne de crédit selon les modalités contractuelles de l'émetteur.
Synonymes / variantes : credit card
Expressions : régler avec une carte de crédit

3. Carte prépayée
Définition : Carte chargée au préalable d'une valeur monétaire utilisable pour effectuer des paiements.
Synonymes / variantes : carte rechargeable; prepaid card
Expressions : recharger une carte prépayée

4. Carte virtuelle
Définition : Carte de paiement dématérialisée dont les données peuvent être utilisées pour des paiements en ligne.
Synonymes / variantes : e-card; virtual card
Expressions : générer une carte virtuelle

5. Code PIN
Définition : Code personnel utilisé pour authentifier certaines opérations réalisées avec une carte ou un dispositif.
Synonymes / variantes : code confidentiel
Expressions : saisir son code PIN

6. DAB
Définition : Distributeur automatique de billets permettant notamment le retrait d'espèces.
Synonymes / variantes : ATM; distributeur
Expressions : retirer de l'argent au DAB

7. GAB
Définition : Guichet automatique bancaire proposant plusieurs services automatisés, selon l'équipement et la banque.
Synonymes / variantes : automate bancaire
Expressions : consulter son solde au GAB

8. TPE
Définition : Terminal de paiement électronique utilisé par un commerçant pour accepter des paiements électroniques.
Synonymes / variantes : terminal de paiement; POS
Expressions : effectuer un paiement sur TPE

9. Acquéreur
Définition : Établissement ou prestataire qui traite les paiements par carte pour le compte d'un commerçant.
Synonymes / variantes : acquirer
Expressions : contrat d'acquisition commerçant

10. Émetteur de carte
Définition : Établissement qui délivre une carte de paiement et gère la relation avec son porteur.
Synonymes / variantes : issuer
Expressions : banque émettrice de la carte

11. Porteur de carte
Définition : Personne autorisée à utiliser une carte de paiement.
Synonymes / variantes : cardholder
Expressions : identifier le porteur de carte

12. Autorisation de paiement
Définition : Réponse du système ou de l'émetteur autorisant ou refusant une transaction.
Synonymes / variantes : authorization
Expressions : demander une autorisation

13. Plafond de paiement
Définition : Montant maximal de paiements autorisé sur une période ou dans des conditions définies.
Synonymes / variantes : limite de paiement
Expressions : augmenter le plafond de la carte

14. Opposition sur carte
Définition : Mesure visant à empêcher l'utilisation d'une carte, notamment en cas de perte, vol ou compromission.
Synonymes / variantes : blocage de carte
Expressions : faire opposition à sa carte

15. Tokenisation
Définition : Remplacement des données sensibles de carte par un identifiant substitutif utilisable dans un environnement sécurisé.
Synonymes / variantes : tokenization
Expressions : tokeniser une carte

########################################################################
MOBILE MONEY ET FINTECH
########################################################################

1. Monnaie électronique
Définition : Valeur monétaire stockée sous forme électronique, représentant une créance sur son émetteur et utilisable pour effectuer des paiements.
Synonymes / variantes : e-money; monnaie numérique électronique
Expressions : émettre de la monnaie électronique

2. Portefeuille électronique
Définition : Service permettant de conserver et d'utiliser une valeur ou des moyens de paiement sous forme numérique.
Synonymes / variantes : wallet; e-wallet
Expressions : alimenter son portefeuille électronique

3. Mobile money
Définition : Service financier permettant d'effectuer des opérations monétaires au moyen d'un téléphone mobile.
Synonymes / variantes : argent mobile; mobile wallet
Expressions : envoyer de l'argent par mobile money

4. Cash-in
Définition : Opération consistant à convertir des espèces en valeur disponible dans un portefeuille ou un compte numérique.
Synonymes / variantes : dépôt cash; alimentation en espèces
Expressions : faire un cash-in chez un agent

5. Cash-out
Définition : Opération consistant à retirer en espèces une valeur détenue dans un portefeuille ou un compte numérique.
Synonymes / variantes : retrait cash
Expressions : effectuer un cash-out

6. USSD
Définition : Protocole de communication utilisé par des téléphones pour accéder à des services via des codes courts de type *XXX#.
Synonymes / variantes : menu USSD; code court
Expressions : composer le code USSD

7. QR code de paiement
Définition : Code visuel permettant d'initier ou d'identifier un paiement à l'aide d'un appareil compatible.
Synonymes / variantes : code QR; QR payment
Expressions : scanner le QR code du marchand

8. Agent de monnaie électronique
Définition : Point de service autorisé à effectuer certaines opérations pour le compte d'un émetteur de monnaie électronique.
Synonymes / variantes : agent mobile money
Expressions : déposer chez un agent

9. Interopérabilité
Définition : Capacité de systèmes ou prestataires différents à échanger des données et à exécuter des opérations entre eux.
Synonymes / variantes : interconnection; interoperability
Expressions : transférer entre deux réseaux interopérables

10. API bancaire
Définition : Interface logicielle permettant à des applications autorisées d'échanger des données ou d'initier des services bancaires.
Synonymes / variantes : interface de programmation bancaire
Expressions : connecter une API bancaire

11. Open Banking
Définition : Modèle permettant, avec consentement et dans un cadre sécurisé, le partage de données bancaires ou l'accès à des services par des tiers autorisés.
Synonymes / variantes : banque ouverte
Expressions : autoriser l'accès à ses données bancaires

12. Agrégateur de paiement
Définition : Prestataire qui regroupe ou facilite l'accès à plusieurs moyens de paiement pour un commerçant ou une plateforme.
Synonymes / variantes : payment aggregator
Expressions : intégrer un agrégateur de paiement

13. Fintech
Définition : Entreprise ou solution qui utilise la technologie pour fournir ou améliorer des services financiers.
Synonymes / variantes : technologie financière
Expressions : solution fintech de paiement

14. Authentification forte
Définition : Vérification de l'identité reposant sur plusieurs facteurs indépendants ou mécanismes renforcés.
Synonymes / variantes : SCA; authentification multifacteur
Expressions : confirmer une opération par OTP

15. OTP
Définition : Code à usage unique envoyé ou généré pour confirmer une connexion ou une transaction.
Synonymes / variantes : one-time password; code à usage unique
Expressions : saisir le code OTP

########################################################################
CRÉDITS ET FINANCEMENT
########################################################################

1. Crédit à la consommation
Définition : Financement accordé à un particulier pour des dépenses non directement liées à l'acquisition d'un bien immobilier.
Synonymes / variantes : prêt à la consommation
Expressions : demander un crédit à la consommation

2. Crédit immobilier
Définition : Prêt destiné notamment à financer l'acquisition, la construction ou la rénovation d'un bien immobilier.
Synonymes / variantes : prêt immobilier
Expressions : constituer un dossier de crédit immobilier

3. Crédit professionnel
Définition : Financement destiné aux besoins d'une activité professionnelle ou d'une entreprise.
Synonymes / variantes : prêt professionnel
Expressions : solliciter un crédit professionnel

4. Crédit de trésorerie
Définition : Financement à court terme destiné à couvrir un décalage temporaire de trésorerie.
Synonymes / variantes : facilité de trésorerie
Expressions : obtenir un crédit de trésorerie

5. Crédit-bail
Définition : Contrat de location d'un bien avec possibilité d'acquisition à l'échéance selon les conditions prévues.
Synonymes / variantes : leasing
Expressions : financer un équipement en crédit-bail

6. Crédit renouvelable
Définition : Crédit dont le montant disponible se reconstitue au fur et à mesure des remboursements, dans les limites du contrat.
Synonymes / variantes : réserve d'argent
Expressions : utiliser une réserve de crédit

7. Capital emprunté
Définition : Montant principal mis à disposition de l'emprunteur, hors intérêts et frais.
Synonymes / variantes : principal; montant du prêt
Expressions : rembourser le capital emprunté

8. Taux nominal
Définition : Taux d'intérêt contractuel appliqué au capital selon les modalités du crédit.
Synonymes / variantes : taux d'intérêt nominal
Expressions : comparer les taux nominaux

9. TAEG
Définition : Taux annuel effectif global exprimant le coût annuel total du crédit selon les règles applicables.
Synonymes / variantes : taux effectif global
Expressions : comparer les TAEG

10. Échéance
Définition : Date à laquelle une somme doit être payée ou remboursée.
Synonymes / variantes : date d'exigibilité; due date
Expressions : payer l'échéance mensuelle

11. Mensualité
Définition : Montant périodique dû chaque mois au titre d'un crédit ou d'un contrat.
Synonymes / variantes : paiement mensuel
Expressions : calculer la mensualité du prêt

12. Tableau d'amortissement
Définition : Document détaillant, échéance par échéance, la répartition entre capital remboursé, intérêts et solde restant dû.
Synonymes / variantes : échéancier d'amortissement
Expressions : éditer le tableau d'amortissement

13. Différé de remboursement
Définition : Période pendant laquelle le remboursement du capital, ou parfois de certaines sommes, est reporté selon le contrat.
Synonymes / variantes : différé de paiement
Expressions : bénéficier d'un différé

14. Pénalité de retard
Définition : Somme ou majoration due en cas de paiement effectué après la date prévue, dans les limites légales et contractuelles.
Synonymes / variantes : frais de retard
Expressions : calculer les pénalités de retard

15. Garantie hypothécaire
Définition : Sûreté portant sur un bien immobilier pour garantir le remboursement d'une dette.
Synonymes / variantes : hypothèque
Expressions : prendre une garantie hypothécaire

16. Cautionnement
Définition : Engagement d'une personne ou entité à payer si le débiteur principal n'exécute pas son obligation.
Synonymes / variantes : caution; garantie personnelle
Expressions : fournir une caution

17. Nantissement
Définition : Affectation d'un bien meuble ou d'un droit en garantie d'une obligation.
Synonymes / variantes : gage selon le régime juridique
Expressions : nantir un fonds de commerce

18. Défaut de paiement
Définition : Non-exécution d'une obligation de paiement à son échéance.
Synonymes / variantes : impayé; défaillance
Expressions : déclarer un défaut de paiement

19. Restructuration de dette
Définition : Modification des modalités de remboursement d'une dette afin de traiter une difficulté financière.
Synonymes / variantes : rééchelonnement; refinancement selon le cas
Expressions : négocier une restructuration

20. Capacité d'endettement
Définition : Part des revenus qu'un emprunteur peut consacrer au remboursement de ses dettes selon les critères retenus.
Synonymes / variantes : capacité de remboursement
Expressions : évaluer la capacité d'endettement

########################################################################
ÉPARGNE, PLACEMENT ET INVESTISSEMENT
########################################################################

1. Dépôt à terme
Définition : Dépôt bloqué pendant une durée convenue, rémunéré selon des conditions définies au contrat.
Synonymes / variantes : DAT; term deposit
Expressions : ouvrir un dépôt à terme

2. Intérêt simple
Définition : Intérêt calculé uniquement sur le capital initial pendant la période considérée.
Synonymes / variantes : rémunération simple
Expressions : calculer les intérêts simples

3. Intérêt composé
Définition : Intérêt calculé sur le capital initial augmenté des intérêts précédemment acquis.
Synonymes / variantes : capitalisation des intérêts
Expressions : appliquer les intérêts composés

4. Taux de rendement
Définition : Mesure du revenu ou du gain obtenu par rapport au montant investi, selon une méthode définie.
Synonymes / variantes : rentabilité; yield
Expressions : calculer le rendement annuel

5. Obligation
Définition : Titre de créance représentant un emprunt émis par un État, une entreprise ou une autre entité.
Synonymes / variantes : bond; titre obligataire
Expressions : souscrire une obligation

6. Action
Définition : Titre représentant une fraction du capital d'une société et pouvant conférer des droits financiers et politiques.
Synonymes / variantes : part sociale cotée selon le contexte; share
Expressions : acheter des actions

7. Dividende
Définition : Part du bénéfice distribuée aux actionnaires sur décision de l'organe compétent.
Synonymes / variantes : distribution
Expressions : percevoir un dividende

8. Fonds d'investissement
Définition : Véhicule collectif qui rassemble des capitaux pour les investir selon une stratégie définie.
Synonymes / variantes : fonds collectif; investment fund
Expressions : souscrire à un fonds

9. OPCVM
Définition : Organisme de placement collectif en valeurs mobilières soumis à un cadre réglementaire spécifique.
Synonymes / variantes : fonds d'investissement réglementé
Expressions : investir dans un OPCVM

10. Portefeuille d'investissement
Définition : Ensemble des actifs financiers détenus par un investisseur.
Synonymes / variantes : portfolio
Expressions : diversifier son portefeuille

11. Diversification
Définition : Répartition des investissements entre plusieurs actifs ou catégories afin de limiter la concentration du risque.
Synonymes / variantes : allocation diversifiée
Expressions : diversifier ses placements

12. Plus-value
Définition : Gain résultant de la différence positive entre le prix de cession et le coût d'acquisition, selon les ajustements applicables.
Synonymes / variantes : gain en capital; capital gain
Expressions : réaliser une plus-value

13. Moins-value
Définition : Perte résultant de la différence négative entre le prix de cession et le coût d'acquisition.
Synonymes / variantes : perte en capital
Expressions : constater une moins-value

14. Liquidité d'un actif
Définition : Facilité avec laquelle un actif peut être converti en espèces sans perte importante de valeur.
Synonymes / variantes : liquidité de marché
Expressions : évaluer la liquidité d'un actif

15. Horizon de placement
Définition : Durée pendant laquelle un investisseur prévoit de conserver un investissement.
Synonymes / variantes : durée d'investissement
Expressions : définir son horizon de placement

########################################################################
MARCHÉS FINANCIERS ET INSTRUMENTS
########################################################################

1. Marché primaire
Définition : Marché sur lequel des titres financiers sont émis et proposés pour la première fois aux investisseurs.
Synonymes / variantes : primary market
Expressions : émettre des obligations sur le marché primaire

2. Marché secondaire
Définition : Marché sur lequel des titres déjà émis sont échangés entre investisseurs.
Synonymes / variantes : secondary market
Expressions : négocier sur le marché secondaire

3. Cotation
